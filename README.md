# Multidimensional-Data-Structures
 Implementation and Experimental Evaluation of  Multidimensional Data Structures  


Τα KD-Tree και R-Tree υλοποιήθηκαν και αξιολογήθηκαν σε 5 διαστάσεις (release_year, popularity, vote_average, runtime, budget), σύμφωνα με το k≤5 της εκφώνησης.
Το QuadTree και το RangeTree που υλοποιήθηκαν είναι εγγενώς διδιάστατες δομές στη συγκεκριμένη υλοποίηση, οπότε αξιολογήθηκαν σε 2D προβολή των δεδομένων (popularity, vote_average). Η ομοιότητα σε textual attribute (genre_names) πραγματοποιήθηκε με MinHash LSH και τα τελικά αποτελέσματα προέκυψαν ως τομή (range results ∩ LSH candidates) και κατάταξη top-N με Jaccard.”
